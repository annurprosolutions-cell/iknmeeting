# Perbezaan Pelaksanaan daripada Dokumen Reka Bentuk (BSD/AFD/IPD)

Perubahan yang dibuat atas permintaan client atau kerana keadaan teknikal. Disenaraikan supaya dokumen asal tidak mengelirukan semasa penerimaan.

| Perkara | Dokumen asal | Pelaksanaan | Sebab |
|---|---|---|---|
| Nama sistem | e-Mesyuarat IKN | **SyuraDocs** (folder Drive akar masih bernama "e-Mesyuarat IKN") | Permintaan client |
| Jenis mesyuarat | Medan Jenis | Dibuang; Tajuk = senarai tiga nama mesyuarat (tetapan) | Client |
| Siri | Siri mesyuarat | **Bilangan** (Bil.1/2026) + Tahun | Client |
| Pengerusi | Peranan tetap | **Per mesyuarat**: mana-mana pengguna Aktif | Client |
| Akses Ahli/Pengerusi | Termasuk Minit dan Tindakan | Ahli: Agenda, Bahan, Komen & Cadangan, Ahli & Kehadiran; Minit hanya bila Disahkan; Tindakan hanya milik sendiri | Client: "taknak mereka masuk sampai ke admin" |
| Muat naik | Setiausaha dan pembentang | Setiausaha (pembentang boleh untuk item sendiri) | Client |
| Cadangan ahli | Fasa 4 | Komen/Cadangan/Soalan/Bantahan, boleh dihadkan kepada Pengerusi & Setiausaha | Client minta ahli taip cadangan semasa mesyuarat |
| Keterlihatan minit | Draf dan Disahkan | **Draf**: staf sahaja; **Untuk Semakan**: staf + Pengerusi mesyuarat itu; **Disahkan**: semua ahli | Aliran pengesahan Pengerusi |
| Pengesah minit | Pengerusi/Setiausaha | Pengerusi mesyuarat itu atau Admin; **Setiausaha tidak boleh**. Hanya Admin boleh buka semula | Asingkan penyedia dan pelulus |
| Penyemak kedua minit | Disebut sebagai pilihan | **Tidak dibina**; hanya Pengerusi menyemak | Ditangguh; boleh ditambah |
| Maklum balas tindakan | Medan Catatan | "Maklum Balas" ditulis pemilik; jadual cetak BIL/PERKARA/TINDAKAN/MAKLUM BALAS | Meniru dokumen sebenar IKN |
| Penyimpanan bahan | Muat naik ke Drive | **Muat naik sahaja** (Fasa 3) + imbas folder Drive | Pilihan client |
| Bahan Bicara | — | Folder `Terhad`; Pengerusi mesyuarat itu dan staf sahaja | Client |
| Nota peribadi | Server | **Pelayar peranti sahaja** (Admin pun tak boleh baca) | Privasi |
